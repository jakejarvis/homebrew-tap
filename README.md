# jakejarvis/tap

Homebrew casks for [Clicker](https://clicker.jarv.is/), a menu bar remote for Apple TV.

```bash
brew install --cask jakejarvis/tap/clicker
```

Clicker updates itself through Sparkle, so `brew upgrade` leaves it alone unless you pass `--greedy`. The cask is bumped automatically by Clicker's release workflow.
